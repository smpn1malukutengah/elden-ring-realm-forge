## ✨ Overview

Elden Ring is a game about discovery, but discovery can sometimes be gated behind ruthless difficulty spikes, obscure quest lines, and RNG that feels more like a capricious god than a game system. **Elden Ring Trainer** was born from a simple wish: let players decide how much friction they want.

Think of this tool as a *lens* — it does not replace the game, it reframes it. You still swing your sword, you still dodge the Waterfowl Dance, but now you can adjust the variables that shape your experience. Want to test a glass-cannon mage build without farming larval tears? Want to explore Leyndell at a leisurely pace without worrying about rune loss? The trainer gives you the dials; you choose the music.

This project is maintained by a small collective of tinkerers, lore enthusiasts, and UI perfectionists. We believe in transparency, community feedback, and the idea that a single-player experience should be *yours* to shape.

## 🎯 Feature Highlights

Every module in Elden Ring Trainer is designed with a *no-nonsense* philosophy: toggle it, tune it, forget it. Below is a curated list of what you can expect.

- **Player Stat Editor** — Adjust Vigor, Mind, Endurance, Strength, Dexterity, Intelligence, Faith, and Arcane in real time. Perfect for testing hybrid builds without respeccing.
- **Rune Multiplier** — Scale rune gains from defeated foes. Ideal for players who want to reduce grind while still earning their progression.
- **Item Discovery Tuner** — Nudge drop rates for crafting materials, rare weapons, and armor sets. The Lands Between becomes a little more generous.
- **No Rune Loss on Defeat** — Keep your hard-earned currency when you fall in battle. Death becomes a lesson, not a punishment.
- **Infinite Item Usage** — Consumables like Flask of Crimson Tears, throwing pots, and boluses stay replenished. Experiment freely.
- **Stealth Mode for Exploration** — Reduce enemy detection range so you can appreciate the environmental storytelling without constant ambushes.
- **Time-of-Day Control** — Shift from dawn to dusk to midnight. Some quests and visuals only shine under certain skies.
- **Weather Manipulation** — Summon rain, clear skies, or the eerie fog of Liurnia at will.
- **Boss Reset Utility** — Relive your favorite encounters without starting a new journey. Practice makes perfection.
- **Save State Snapshots** — Capture your character’s current configuration and restore it later. A safety net for the bold.
- **Hotkey Binding** — Assign any module to a keyboard shortcut for instant access.
- **Overlay HUD** — A minimal, non-intrusive on-screen display shows active modules at a glance.
- **Profile System** — Save multiple presets: one for a relaxed lore run, one for a hardcore challenge, one for build testing.
- **Auto-Backup** — Periodic save file backups ensure you never lose progress to an accidental toggle.

Each feature is documented in-game via tooltips and in this README. We believe that *clarity is kindness*.

## 🖥️ Responsive Interface & Design Philosophy

The interface of Elden Ring Trainer is built around a simple question: *how little can we show while still being useful?* The answer is a sleek, adaptive panel that scales from a 720p laptop screen to an ultrawide monitor. Buttons rearrange themselves based on window size, and the color palette draws inspiration from the game’s own UI — muted golds, deep blues, and the soft glow of grace.

The design is **responsive** not just in layout, but in interaction. Hover states are subtle, animations are brief, and every action provides immediate feedback. There is no lag between your intent and the result.

We also prioritized **accessibility**: high-contrast mode, adjustable font sizes, and full keyboard navigation. The Lands Between are for everyone.

## ⚙️ Configuration & Customization

Elden Ring Trainer stores its settings in a portable configuration file, making it easy to move between machines. The config is human-readable and version-controlled, so you can track changes over time.

Advanced users can:

- Create **module chains** that activate in sequence.
- Set **conditional triggers** (e.g., enable stealth only when HP is below 30%).
- Export and import profiles as plain text.
- Use a **CLI companion** for headless adjustments (for the true terminal wizards).

The goal is flexibility without chaos. Every option is documented, every default is sensible.

## 📊 Stat & Attribute Modules

The stat editor deserves its own spotlight. Unlike crude memory editors, our approach uses **safe write intervals** and **validation checks** to prevent out-of-range values that could corrupt your save. You can:

- Set stats to any value between 1 and 99 (or beyond, with an advanced warning).
- Lock stats so they don’t reset after fast travel.
- Apply **soft caps** automatically to avoid diminishing returns confusion.
- Preview derived attributes (HP, FP, Stamina, Equip Load) in real time.

This module is a dream for theorycrafters who want to test a build before committing to a full playthrough.

## 🛡️ Safety & Integrity Notes

We take the longevity of your save files seriously.

- **Automatic backups** are created before any write operation.
- **Checksum validation** ensures the trainer does not introduce malformed data.
- **Read-only mode** is available for players who just want to inspect values.
- **No kernel-level drivers** are used. The trainer operates in user space.

That said, no third-party tool is 100% risk-free. We recommend using a dedicated save profile for experimentation.

## 📚 Frequently Asked Questions

**Q: Will this affect my multiplayer experience?**  
A: The trainer is designed for offline and single-player sessions. Using it in online play may violate the game’s terms of service and could result in soft bans. We strongly advise against it.

**Q: Do I need to disable Easy Anti-Cheat?**  
A: The trainer includes a launcher option that handles this automatically for offline mode. Always play offline when using the trainer.

**Q: Can I revert changes?**  
A: Yes — every module has an undo option, and your backup saves are your safety net.

**Q: Is there a mobile version?**  
A: No, but the interface is responsive enough to be controlled via remote desktop on a tablet.

**Q: How often is the trainer updated?**  
A: We aim for monthly maintenance releases and hotfixes as needed.
